Home

Overview

#home

Nginx Proxy Manager is a reverse proxy management UI with SSL automation. This add-on wraps the official jc21/nginx-proxy-manager image with HA Supervisor integration, secrets support and optional MariaDB backend.

nginx   → proxies :80/:443 to internal services

Installation

Install the Add-on

#installation

#Step 1 — Add Repository

  1. Open Home Assistant.
  2. Go to Settings → Add-ons → Add-on Store.
  3. Open ⋮ → Repositories.
  4. Add:
https://github.com/pol4rfuchs/ha-apps

#Step 2 — Install

  1. Search for Nginx Proxy Manager.
  2. Click Install.

#Step 3 — Start

  1. Enable Start on boot.
  2. Click Start.
  3. Open the Admin UI at port 81.
Ports 80 and 443 must be free on the host. Disable any other service using these before starting.

Configuration

Options & Secrets

#configuration

#SQLite (Default)

No configuration required. NPM creates its own SQLite database under /data/npm/ on first start.

#MariaDB Backend

Install and start the HA MariaDB add-on, then create the database and user before enabling this option.

db_type: mariadb
mariadb_host: core-mariadb
mariadb_port: 3306
mariadb_name: npm
mariadb_user: npm

Password goes in secrets.yaml, not the add-on config:

mariadb_password: "dein_passwort"
npm_jwt_secret: "einlangesrandommjwtsecret"
The DB password and JWT secret are no longer add-on config options — they were moved out of options/schema into secrets.yaml for security.

First Start

Setup Wizard

#first-start

#Create the Admin Account

URL:      http://homeassistant.local:81

On first start NPM shows a setup wizard (Welcome! Get started by creating your admin account.). Enter full name, email address and a password, then save. There is no default login (admin@example.com / changeme) since NPM 2.13.

Finish the wizard right after the first start. Until then, anyone on your LAN who can reach port 81 can create the admin account. Existing installations keep their credentials after an update.

#Create Your First Proxy Host

  1. Click Proxy Hosts → Add Proxy Host.
  2. Set the domain name (e.g. ha.yourdomain.com).
  3. Set the forward hostname to homeassistant.local or HA IP.
  4. Set the forward port to 8123.
  5. Enable SSL under the SSL tab.
🔐

SSL & Let's Encrypt

Certificate Management

#ssl

#HTTP-01 Challenge

Requires port 80 to be forwarded to your HA host. Works for standard domain certificates.

#DNS-01 Challenge (Recommended)

Works without port forwarding. Supports wildcard certificates. Available providers in NPM include Cloudflare, DuckDNS, Route53 and more.

  1. SSL Certificates → Add SSL Certificate → Let's Encrypt.
  2. Enable Use DNS Challenge.
  3. Select your DNS provider.
  4. Enter your API credentials.

#DuckDNS Setup

Provider:     DuckDNS
Token:        your-duckdns-token
Domain:       your-subdomain.duckdns.org
DuckDNS wildcard certs cover *.your-subdomain.duckdns.org — useful for multiple subdomains on one certificate.

#Auto-Renewal

NPM renews certificates automatically before expiry. No manual action required after initial setup.

Ports & Networking

Port Reference

#ports
PortProtocolPurposeExpose publicly?
80/tcpHTTPProxy + ACME HTTP-01 challengeYes (for HTTP)
443/tcpHTTPSProxy (SSL)Yes (for HTTPS)
81/tcpHTTPNPM Admin UINo — LAN only
Never expose the Admin UI (port 81) to the internet. Keep it behind your LAN or VPN.

#Local and external access

Local (LAN): the admin UI runs directly on port 81 (http://<ha-host>:81), not through Ingress. The port is mapped on the host and reachable across your LAN. Finish the setup wizard and create the admin account right after the first start, the UI is unprotected until then.

External (internet): ports 80 and 443 are the entrance for proxy traffic and may be forwarded on your router; that is the purpose of this add-on. Never expose port 81 to the internet, LAN or VPN only.

Persistence

Data & Backup

#persistence 
/data/
├── database.sqlite    # NPM database (if not using MariaDB)
├── nginx/             # Generated nginx configurations
└── letsencrypt/       # Let's Encrypt certificates and ACME data
Important: The letsencrypt/ folder contains your private keys and certificates. HA backups include it automatically.

#Backup Workflow

  1. Settings → System → Backups → Create Backup.
  2. This captures NPM config, certificates and (if SQLite) the database.
  3. For MariaDB: also back up the MariaDB add-on data.

Troubleshooting

Known Symptoms & Fixes

#troubleshooting
SymptomCauseFix
Port 81 not accessiblePort not mapped in Network tab.Add port mapping in add-on Network settings.
Port 80/443 conflictAnother service uses these ports.Stop conflicting service or change its port.
Let's Encrypt failsPort 80 not forwarded (HTTP-01).Use DNS-01 challenge or forward port 80 on router.
MariaDB connection refusedWrong credentials or MariaDB not running.Verify MariaDB add-on is running and credentials match.
White screen on UIBrowser cache issue.Clear cache and try direct URL: http://HA-IP:81
Proxy host returns 502Upstream service not running or wrong port.Verify the forwarded service is running and the port is correct.
